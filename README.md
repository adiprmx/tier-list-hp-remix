# Tier List HP Remix

Halaman perbandingan HP untuk ngeremix (FL Studio Mobile), hasil riset mendalam
14 November 2026. Satu file HTML mandiri — buka `index.html` langsung di
browser, tanpa build dan tanpa server.

Halaman live: https://adiprmx.github.io/tier-list-hp-remix/

## Kriteria

- Chipset kencang, RAM lega (8GB min, 12GB ideal), storage 256GB+ (512GB ideal)
- Jack headset 3,5mm WAJIB, speaker stereo, layar AMOLED, refresh rate 120Hz+
- 5G dan slot microSD
- Android di bawah 16 (keluarga Xiaomi di bawah 14)
- Awet untuk jangka panjang

## Ringkasan hasil

- **Satu-satunya yang lolos semua kriteria dan dijual resmi di Indonesia:
  Redmi Note 14 5G 12/512, Rp3.699.000** (Dimensity 7025 Ultra).
- Chipset jauh lebih kencang hanya ada di Sony Xperia impor: 1 VI Rp20–27jt,
  1 VII Rp27,5–29,5jt (pernah kena cacat power — verifikasi IMEI), 1 VIII
  Rp30,5–40jt.
- Lepas jack: Motorola Edge 60 Pro resmi Rp7,5–10jt (Dimensity 8350).
- FL Studio Mobile v5.0.5 (Rp100.000 di Play Store Indonesia): tidak ada
  pernyataan resmi soal Android 15/16; satu laporan terkonfirmasi audio mati
  total di Android 16/HyperOS 3 (Redmi 14C). Android 14 adalah titik aman.
